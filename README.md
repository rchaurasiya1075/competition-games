# competition-games

Janata Akhada is the main two-player arena: pick a name, choose a politician character, customise skin, face, body and clothes, then play ten head-to-head games. One winner per match. Levels, music, and match recording are built in.

Open `akhada/index.html` (GitHub Pages: `/akhada/`).

Older canvas arenas are still here: Auto Ball Arena, Ball Battle, Car Clash, Missile Mayhem, Hero Clash, Crystal Race, and Survival.
